## Key Patterns & Conventions

### Authentication
- All protected endpoints use `Depends(_get_current_user)` dependency
- Bearer token in `Authorization: Bearer {jwt_token}` header
- Passwords hashed with bcrypt, tokens with HS256

### Request/Response
- All endpoints use Pydantic models for validation
- Errors return `HTTPException` with appropriate status codes (400, 401, 403, 404, 500)

### Database
- SQLAlchemy async ORM with PostgreSQL + asyncpg driver
- All queries use async/await
- Models in [backend/db/models.py](backend/db/models.py) (TODO)
- Schemas in [backend/db/schemas.py](backend/db/schemas.py) (TODO)

### Services
- Singleton pattern: Initialize once at startup, share across requests
- Dependency injection via FastAPI `Depends()`
- Each service independently testable

## When Working on Endpoints

1. **Define Pydantic models** in [backend/db/schemas.py](backend/db/schemas.py)
   - RequestModel: Input validation
   - ResponseModel: Output shape

2. **Create SQLAlchemy models** in [backend/db/models.py](backend/db/models.py)
   - Table schema and relationships

3. **Implement service** in `backend/api/{resource}.py`
   - Use patterns from [backend/api/auth.py](backend/api/auth.py)
   - Async functions with `async def`
   - Use `Depends(_get_current_user)` for protected endpoints

4. **Register router** in [backend/main.py](backend/main.py)
   ```python
   from backend.api import presentations_router
   app.include_router(presentations_router, prefix="/presentations", tags=["presentations"])
   ```

## Common Gotchas

- **CORS errors:** Add frontend domain to `CORS_ORIGINS` in `.env`
- **DB connection fails:** Verify `DATABASE_URL` format and credentials
- **Token expired:** Implement refresh token endpoint
- **Cloud SQL from Cloud Run:** Use Unix socket connection, not TCP
- **Email not sending:** Configure SMTP variables (SMTP_HOST, SMTP_USERNAME, etc.)
